Maps → Garmin

Paste a Google Maps share link (or shared text) to download a TCX course for Garmin Connect (GPX available with ?gpx=1).

iOS Shortcut

Build a Shortcut named “Save to Garmin” with these actions, then add it to your Share Sheet so it appears when sharing from Maps:

  1. Receive URLs and Text from Share Sheet
  2. Get Contents of URL — Method POST, URL , Headers Content-Type: application/json, Request Body (JSON): { "text": "Shortcut Input" } (use the variable for the value)
  3. Save File — choose iCloud Drive / Files; name it course.tcx
  4. (Optional) Open File in Garmin Connect to import

On Android, install this PWA from the browser menu (“Add to Home screen”). The Maps share target will then list it directly.
